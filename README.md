# 観覧車パズル

このプロジェクトは、タッチ・マウス操作で回転できる観覧車風の SVG 画面です。

## 使い方

1. ブラウザで index.html を開きます。
2. 観覧車の内側を指またはマウスのドラッグで回して、配置を調整します。マウスでクリックすると時計回りに1目盛り進みます。
3. 画面右下の小さな領域を指またはマウスの左ボタンで 3 秒ほど長押しすると、管理画面を開けます。
4. 分割数やアイコンを変更して適用できます。

## 主要ファイル

- index.html: ページの土台
- style.css: 見た目のスタイル
- script.js: 観覧車の描画と操作ロジック

## 備考

- iPad でも使いやすいように、タッチ操作に対応しています。
- 画面はシンプルに表示されるように整理しています。
- 単体版の `観覧車.html` でも、タッチ・マウスで同じ回転操作ができます。

## 動作確認

`node --test tests/input.test.js` でマウス・タッチ操作と設定の回帰テストを実行できます（外部パッケージ不要）。
